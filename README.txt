BIRTHDAY UNLOCK
29 November 2026 at 12:00 AM India Standard Time (IST, UTC+05:30).
The public page stays locked until the date/time. At midnight, the visitor must tap the unlock button.

PRIVATE PREVIEW
Open the website URL with ?preview=1 at the end, for example:
https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/?preview=1
This is a convenience preview switch, not password protection. Anyone with the preview URL can open it, so share the normal URL with Aman.

PUBLISH ON GITHUB PAGES
1. Create a new public GitHub repository.
2. Upload the CONTENTS of this folder (not the outer folder itself), keeping the assets folder structure.
3. In repository Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
4. Wait for GitHub Pages to publish, then open the URL it provides.

MUSIC NOTE
Mobile browsers may block autoplay. The visitor can start or pause the uploaded song using the music control. Background playback may pause when the browser or phone suspends the page.
